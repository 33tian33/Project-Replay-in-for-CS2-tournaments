OBS 网页输出

浏览器源放在直播画面上方，平时透明。回放顺序：转场 1 → 列表 → 转场 2 → 透明。

转场支持 MP4 / WebM（透明转场需带 Alpha 的 WebM），单文件不超过 256 MB。未导入的转场跳过；快捷键播放当前回合。OBS 中请关闭“不可见时关闭源”和“场景激活时刷新浏览器”。

自定义 HUD

Astra HUD 随 Replay 内置，无需上传 ZIP 或启动其他 HUD 服务，直接接收 Replay 的完整 GSI。OpenHUD 选项复用已有 OBS 源，需先运行 OpenHUD。ZIP HUD 可直接在录制控制区上传并自动启用；包含 index.html，或用 replay-hud.json 指定入口。其他接入方式需先启动独立 HUD 程序并配置它的游戏数据接入。网页地址必须能从 Linux 录制机访问；127.0.0.1 指这台 Linux。OpenHUD 使用其提供的透明网页输出。只有窗口输出的程序，请在无头显示器 :20 运行，并在无头 OBS 中添加窗口采集源。

切换时只保留所选 HUD，清理旧 ZIP HUD 及同名重复叠加。已有 OBS 源保留原来的尺寸、裁剪和滤镜。选择内置战队 HUD 可切回内置样式。
