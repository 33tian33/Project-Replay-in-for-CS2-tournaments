# Windows 网页回放更新

## 使用

打开便携 EXE，在下方「OBS 网页输出」复制地址，添加至 OBS 浏览器源，放在直播画面上方。空闲透明，使用输出源自己的地址，无需在 OBS 登录管理页。导入转场 1、转场 2，支持 MP4、WebM；Alpha 透明转场使用 WebM。

默认开启回合结束、半场精选和比赛结束全场精选自动播出。全场通过 A 路 `map.phase=gameover` 的进入变化触发，包含当前地图全部录制素材（含加时）。半场默认第 12 回合，可修改；A 路 GSI 还支持半场阶段变化。请重新生成并安装 A 路 GSI 配置。本次仅用模拟 payload 验证检测逻辑，真实 CS2 数据包仍需联调。

新素材自动加入所属回合和精选：上半场素材进入半场精选，所有当前地图素材进入全场精选；普通回放只播选定回合。↑↓ 调整顺序，✕ 从列表移除，☆ 一键选入半场精选。半场 / 全场精选独立排序、移除，不删除原素材。播放时保留已选列表顺序，未完成录制和回传的素材就绪后追加，待全部相关任务完成才播放结束转场。切换采集会话会清空旧队列。

回放流程：转场 1 → 视频列表（右上方显示 Replay）→ 转场 2 → 透明。未导入的转场直接跳过。普通回合回放在下一回合出现击杀或倒计时到 1:47 时中止；半场 / 全场精选不受普通回合开始影响；半场替换普通回放，全场替换其他播出。空列表、输出离线或媒体播放失败不会留下遮挡画面。

快捷键默认 Ctrl+Alt+R，在软件中修改，留空禁用；Windows 程序后台运行即可。支持 Ctrl / Alt / Shift 加字母、数字或 F1–F11，注册冲突显示在界面。使用 Windows RegisterHotKey 的线程消息队列，关闭程序时释放注册。参考 [Microsoft RegisterHotKey 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。

## 验证与限制

- Go 服务端测试覆盖回合与会话隔离、列表顺序、半场优先、重复 GSI、冷启动快照、B 路隔离、等待回传、下一回合取消、持久化、转场上传、媒体失败、免密输出和播放端互斥。
- JavaScript 测试覆盖双转场与两条视频连播、下一条预载、Replay 显隐、正常结束透明、自动播放失败、断线与手动停止。
- 本地浏览器实测：演示出片、自动入回合、单击加入半场、普通回放显示 Replay、播放结束透明、两段转场导入、半场触发。普通浏览器首次有声自动播放被阻止，点击输出页激活后正常。
- Windows x64 采用交叉编译，尚未进行 Windows 全局快捷键注册和实际 OBS 验证；Alpha 解码、实际音频路由、真实比赛的 GSI 回合编号与半场时序仍需现场验收。
- OBS 源保持启用，关闭「不可见时关闭源」与「场景激活时刷新浏览器」。只允许一个输出页领取播放；测试完成后关闭普通浏览器测试页。断线约 3 秒恢复透明，单项媒体 120 秒超时。
- OBS 直播音轨是否静音、解说是否保留由 OBS 配置；本软件只提供带视频音频的浏览器源，不调整其他源音量。
- 本更新不改变首版采集精度边界，严格模式仍阻止未核验的实时定位。

### 回合自动回放规则（2026-09-18）

- 设置中的“测试模式”控制 Demo 联调面板显示；真实采集仍选择 `live`，测试开关不改变录制后端。
- 导播端填写 Linux 节点 URL 和 GOTV2 地址，勾选“保存配置时自动将 GOTV2 发至 Linux 并连接”。保存时发送地址并让空闲的 Linux Agent 连接；发送失败会明确提示，本机配置仍保留。两端比赛名称须一致；地图由各端 GSI 自动读取。
- 同一玩家在两秒内的连续击杀、GSI 存活人数确认的 1v2/1v3 残局优先于普通冲突镜头；已提交任务和人工指定仍保留。残局识别需要完整的玩家队伍、存活信息。
- 成片自动进入对应回合列表；未录制和录制中的事件显示在列表末尾。自动播出先播放就绪素材，晚到素材追加在关闭转场之前。尚无就绪视频时输出保持透明等待；失败或错过窗口的事件不会作为视频播放。
- 自动触发只使用导播端 A 路 GSI。手动按钮或全局快捷键成功触发某回合后，该回合结束不再自动触发。手动触发可接管尚未开始的自动播出等待。
- 下一回合开局仍可回放；A 路倒计时到 1:47（或已越过）、出现首杀、导播点击“返回直播”时立即结束会话，晚到视频不会重新拉起该会话。B 路 GSI 不触发播出或切出。

- 地图无需手动输入：Windows 以 A 路、Linux 以 B 路 GSI 为准。换图自动清空旧播出队列和状态并切换时间线；旧素材仍保留。新地图事件遇到 Linux 延迟换图时最多等待 120 秒，超时明确失败。
