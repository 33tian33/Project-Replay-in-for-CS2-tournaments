# 本地 Demo 双路联调与 REPLAY 标签

本版新增“本地 Demo 双路联调”控制区，供 Windows A 路和 Linux B 路使用同一份 CS2 `.dem` 文件模拟双路 GOTV。它实际控制两台 CS2，录制与回传沿用现有真实链路；与使用内置测试视频的“演示一轮”不同。

## 准备两端

1. 更新两端程序。Windows 运行导播端，Linux 运行 Agent；建议用独立测试数据目录（启动参数 `-data`）保留正式会话配置。
2. 将同一份 `.dem` 复制到两台机器。路径可以不同，启动会核对 SHA-256；文件必须同时可被本机 Replay 服务和本机 CS2 读取。文件不会通过网页上传，也不会自动跨机器复制。
3. 两端启动 CS2，开启本机 NetCon（例如启动参数 `-netconport 2121`）。会话设置里的 NetCon 在 Windows 指向 Windows CS2，在 Linux 指向 Linux CS2。Linux 配置已有 CSStudio `session.lock` 路径；Replay 使用同一资源锁避免与录制程序同时操作。
4. 两端设置为真实模式 `live`，填相同比赛、Demo 的实际地图；Windows 填 Linux URL，无需令牌。epoch 是本地版本，程序自动转换，无需手动对齐。
5. 两端安装对应 A/B GSI 配置，Linux 配好 OBS 录制场景、FFmpeg、ffprobe、B 路已核验的选手槽位映射。近似采集测试需关闭严格定位模式。普通击杀测试用 GSI 来源；GSI 不识别道具类型，自动追雷仍需 parser 数据源。

## 操作顺序

1. 分别在两端填写**本机文件路径**，点击“1 · 载入本机 Demo”。程序会在两端各自先执行 `cl_demo_predict 0`，再执行 `playdemo`。等待游戏完成载入；此操作会替换当前游戏中的 Demo / 观战内容。
2. 输入相同起始 tick，分别点击“2 · 定位并暂停”。随后点击“3 · 检查本机就绪”，必须两端都显示已暂停在目标 tick。检查读取 CS2 的实际 tick；载入慢时可以等待后重试。此阶段请勿手动更换 Demo、跳 tick 或改变播放速度。
3. Windows 填“Linux B 路延迟（秒）”，允许 0–300 秒、支持小数，建议先用 15 秒。点击“4 · 启动双路测试”。程序同步节点时钟，并校验两端会话、模式、Demo 文件和起始 tick。
4. Windows A 路在约 5 秒后发送 1 倍速播放命令；Linux B 路在 A 的计划时刻再加自定义延迟后发送播放命令。状态显示倒计时及本机发送完成时间。网页可以关闭，倒计时由服务端执行。程序重启不恢复待执行启动。
5. **等待两路都实际播放后**，通过相同击杀、回合计时等画面实测 B 落后 A 的时间，在两端“会话设置 → 实测游戏时间线”应用相同差值和误差，然后分别启用采集。这不需要再次保存整份会话配置。设置的启动延迟只用于模拟，不能证明渲染帧已同步；测试启动不会自动伪造校准，也不会自动开启采集。
6. Windows 观察 GSI 候选 → 调度 → Linux 录制 → 素材回传及 SHA-256 校验 → 回合列表；连接 Windows OBS 网页输出，点击“播出此回合”验证回放与标签。候选太靠近启用时间可能错过窗口，观察后续击杀。
7. Windows“停止双路测试”取消待执行启动、暂停两端 Demo 与后续采集。节点断网时会报告失败，可在 Linux 点击“停止本机 Demo”。已锁定录制不会被中断，需等待完成后重试。停止测试与“返回直播”是不同操作。

若某一路启动失败、机器休眠错过启动时刻或 NetCon 不通，状态会显示失败；核对两端并停止，再重新定位、检查就绪和启动。播放中请勿手动暂停、快进、调速或更换 Demo；发生这些操作后需停止测试、重新定位及校准。软件无法仅凭发送成功确认 CS2 已渲染相应帧。

## Windows 回放标签

按 `Replay-tag-source-v2.zip` 中 `ReplayTag.tsx` 的设计移植为内置 HTML/CSS，不增加 Node / Remotion 运行依赖：

- 转场 1 完成、第一段回放实际开始时，REPLAY / BETA 在 0.4 秒内滑入。
- 入场时 REPLAY 为斜体，到位切为正体；多段回放间保持显示，不循环、不重复入场。
- 最后一段回放剩余约 0.4 秒时转为斜体，用 23/60 秒滑出，随后播转场 2，最后恢复透明。
- 按 1920×1080 设计等比适配输出，右上边距 64、标签尺寸 316×152；BETA 保持原设计。
- 手动返回直播、输出断开、解码失败时立即清除标签和画面。未导入转场时仍按上述回放标签时序工作。

字体使用设计原稿的 Arial Black / DejaVu Sans，最终外观会随 Windows / OBS 可用字体有细微差异。

## 验证范围

自动测试使用独立 HTTP 服务和模拟 NetCon，覆盖两端文件不一致、就绪 tick 不符、延迟排程、A 已开始但 B 仍等待、双端取消、过期启动、免配对访问和录制占用保护。网页测试覆盖标签一次入场、跨片段保持、末段退出、手动停止和断线清理。

这些测试不等同于两台真实 CS2 + Windows OBS 的现场验收；实际游戏启动偏差、GSI 行为、录制性能及素材画面仍需按上面的步骤核验。
